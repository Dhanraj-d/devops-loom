# DevOps Loom

A comprehensive, modern website designed for DevOps learners of all skill levels. This website provides structured learning paths, interactive tutorials, and curated resources to help users master DevOps skills from beginner to expert level.

## 🚀 Features

### 📚 Learning Paths
- **Beginner Path**: Introduction to DevOps, Linux fundamentals, Git, basic Docker, and CI/CD concepts
- **Intermediate Path**: Kubernetes orchestration, Infrastructure as Code, monitoring, cloud platforms, and security
- **Advanced Path**: Microservices architecture, advanced Kubernetes, GitOps, service mesh, and DevSecOps

### 🛠️ Tools & Technologies
Comprehensive coverage of essential DevOps tools:
- **Docker** - Containerization platform
- **Kubernetes** - Container orchestration
- **Jenkins** - CI/CD automation
- **AWS** - Cloud computing platform
- **Terraform** - Infrastructure as Code
- **Git** - Version control system

### 🎯 Interactive Tutorials
- Hands-on learning with real-world scenarios
- Difficulty-based progression (Beginner, Intermediate, Advanced)
- Time estimates for each tutorial
- Practical projects and exercises

### 📖 Learning Resources
- **Documentation**: Official docs and best practices
- **Video Tutorials**: Comprehensive video courses
- **Practice Labs**: Hands-on lab environments
- **Community**: Discord servers, forums, and GitHub repositories

## 🎨 Design Features

### Modern UI/UX
- **Responsive Design**: Optimized for desktop, tablet, and mobile
- **Interactive Animations**: Smooth transitions and hover effects
- **Modern Color Scheme**: Professional gradient backgrounds
- **Typography**: Clean, readable Inter font family

### Interactive Elements
- **Floating DevOps Tools**: Animated circles showcasing key technologies
- **Smooth Scrolling**: Seamless navigation between sections
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Hover Effects**: Engaging interactions on cards and buttons

## 🛠️ Technical Stack

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript (ES6+)**: Interactive functionality
- **Font Awesome**: Professional icons
- **Google Fonts**: Inter font family

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px
- **Mobile**: 320px - 767px

## 🔧 Customization

### Adding New Learning Paths
1. Add new path cards in the HTML

3. Update the JavaScript for any new interactions

### Adding New Tools
1. Create new tool cards in the tools section
2. Add appropriate icons and descriptions
3. Update the floating circles in the hero section

### Modifying Content
- Update text content directly in the HTML
- Modify colors and styling in the CSS
- Add new interactive features in JavaScript
